## Why bulk function deletion was not done

A·CEIL uses ordered script loading and wrapper chains. A later definition frequently captures an earlier implementation (`oldFn = window.fn`) and calls it. Other files install DOM listeners, MutationObservers, timers, storage migrations, Supabase wrappers, or initialization at load time. Therefore “the same function name appears later” is not proof that the earlier code is removable.

A concrete example is the old `saveToPhone`: its name is replaced later, but the later report layer captures the previous implementation and uses it as the single-room fallback. Deleting the earlier definition would break reports even though a static name map calls it “overridden”.
