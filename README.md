# A·CEIL

Вебзастосунок для замірів натяжних стель, проєктів, номенклатури, кошторисів і звітів.

## Структура

```text
index.html            точка входу та порядок runtime-модулів
sw.js                 service worker і кеш поточної збірки
VERSION               єдиний build id
assets/               стилі, шрифти та матеріали
js/core/              сховище, діагностика, геометрія та спільні API
js/auth/              авторизація, Supabase та офлайн-доступ
js/projects/          репозиторій, збереження, синхронізація та імпорт проєктів
js/rooms/             кімнати, світло та лінійні елементи
js/canvas/            renderer, viewport, контури, стіни й карнизи
js/nomenclature/      каталог, автопрорахунок, матеріали та ціни
js/reports/           кошториси, звіти та публічні посилання
scripts/              перевірки й утиліти
supabase/migrations/  SQL-міграції
tests/                модульні та браузерні перевірки
docs/history/         завершені технічні звіти та історичні нотатки
```

Порядок підключення скриптів зафіксований у `scripts/runtime-order.json`. Числовий префікс файлу визначає порядок виконання й не є версією.

## Версія збірки

`VERSION`, параметри `?v=` у `index.html`, `BUILD_ID` і кеш у `sw.js`, runtime-версія та перевірка стабільності повинні мати однаковий build id. Актуальність контролює `scripts/check-before-deploy.sh`.

## Зберігання проєктів

`A·CEIL.ProjectRepository` є основним локальним репозиторієм. `A·CEIL.ProjectPersistence` виконує локальний запис перед хмарною синхронізацією. `A·CEIL.ProjectRecovery` зберігає лише незасинхронізовані проєкти та відновлює їх після збою або невдалого хмарного злиття.

Старий ключ `ceiling_projects_backup_v35` читається один раз і без втрати даних переноситься в `aceil_project_recovery`.

## Перевірка

Швидка перевірка перед публікацією:

```bash
bash scripts/check-before-deploy.sh
```

Повний набір:

```bash
bash scripts/run-all-tests.sh
```

Застосунок ще містить глобальні API для сумісності між послідовно завантаженими модулями. Нові обгортки глобальних функцій заборонені архітектурними перевірками; нова логіка має додаватися до відповідного основного модуля.
