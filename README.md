# A·CEIL — STABILITY + ARCHITECTURE GUARD 2026-10-17

Повний пакет для Vercel. У корені публікації мають бути index.html, assets/, js/, sw.js, vercel.json і .vercelignore.
Підмінюйте пакет цілком: він містить перенесені та видалені файли, а не лише додаткові латки.
Домен і налаштування Supabase збережені. Міграція бази даних не потрібна.

## Стабілізація 2026-10-16

- Усі локальні JS/CSS, service worker, ключ перезавантаження PWA і VERSION використовують одну версію `20261018-real-scale1`.
- Оновлення PWA більше не чекає завантаження всіх 159 скриптів: наперед кешується тільки оболонка,
  а версійні JS/CSS кешуються під час першого відкриття нової збірки.
- Safari на телефоні й установлена PWA використовують спільний вбудований перегляд звіту та передають
  у хмару однакове структуроване креслення з прив'язкою до активного проєкту.
- `.vercelignore` не допускає до публічного деплою tests/, scripts/, docs/, кореневі Markdown-файли та VERSION.
- Перемикач мови повторно використовує один `rmAppLangSheet` після перемальовування кокпіта.
- Видалено недоступні legacy-форми кривих стін із відсутніми onclick-обробниками. Робочий hybrid-режим не змінено.
- Прибрано дублікати числових префіксів: admin 167 → 166, insert guard 177 → 179; runtime-порядок збережено.
- До перевірки перед деплоєм додано контроль єдиної версії PWA, `.vercelignore`, унікальних префіксів і відсутності legacy-обробників.
- Додано браузерну регресію окремих довжин, кутів, обривів і світильників світлової лінії та трьох шинопроводів.
- Частковий тіньовий/парящий профіль віднімається від базового алюмінієвого профілю та вставки лише в поточній кімнаті; кути розподіляються за фактичними переходами профілів.
- Пізній автопрорахунок більше не може записати шинопровід у позицію світлової лінії: фінальна синхронізація використовує стабільний ID типу.
- Вибір білої/чорної вставки фіксується до автопрорахунку; якщо обрана біла, кількість отримує саме біла позиція. Без збереженого вибору біла є стандартною.
- До перевірки перед деплоєм додано окремі тести профілів, чотирьох типів лінійного освітлення та вибору вставки.
- Прибрано три порожні повторні JS-обгортки. Перевірка перед деплоєм тепер також блокує
  однакові JS-файли та копії, що відрізняються лише форматуванням.
- Відстані й площа для solver/перевірки замірів беруться зі спільного геометричного ядра.
- Типи лінійного освітлення мають один реєстр стабільних ID; перейменування позиції не змінює автоприв'язку.
- Анонімні `*-inline.js` перейменовано за призначенням без зміни порядку виконання.
- Додано публічну API-заготовку та архітектурний запобіжник: нові обгортки й новий борг тепер блокуються перевіркою.
- Додано golden/storage/PWA-перевірки та чесний `run-all-tests.sh`, який не може написати `ALL OK` після падіння браузерних тестів.

## Базова консолідація

- Єдина draw() у js/canvas/renderer.js. Додаткові шари реєструються через ACEILCanvas.
- js/canvas/viewport.js відокремлює логічні координати від пікселів Retina; враховано збільшене полотно.
- Звіти експортуються у 4× логічному розмірі, без повторного множення на Retina.
- Очищення контуру та попередження геометрії перенесено у відповідальні функції.
- Живе редагування ромба і повороту світла працює всередині модуля лінійних елементів.
- Видалено неактивний оформлювач 035, стару HiDPI-обгортку, окремі латки 125/136/137/192,
  вимкнений переглядач планів і непідключений js/canvas/sw.js.
- Видалено хибне підключення відсутнього 188-wall-dimensions-panel.js: розміри вже малює
  основний renderer. Додаткову панель не створено.
- 9 CSS-файлів → 3. Прибрано 431 точне повторне оголошення; порядок каскаду збережено.
- Поточний пакет містить 3 CSS-файли та 159 локальних runtime-скриптів.
- Порядок залежних модулів збережено та зафіксовано перевіркою.

## Перевірка

`bash scripts/check-before-deploy.sh` (Node.js + Python 3).
Перевіряє файли JS/CSS, синтаксис зовнішніх/вбудованих JS, порядок скриптів та відсутність обгорток draw().

Пройдено 48 автоматизованих браузерних перевірок і 50 перевірок голосового вводу. Подробиці: FINAL_REGRESSION.md.
Для повторення функціональних тестів: `npm install --no-save playwright@1.51.1`,
`npx playwright install chromium`, `node tests/verify-aceil.cjs`, `node tests/verify-state.cjs`.
Для порівняння CSS із попереднім пакетом передайте його папку в ACEIL_BASELINE.

Це консолідація канвасу та очищення пакета. Решта застосунку ще використовує глобальні функції,
історичні обгортки й послідовне завантаження; повним переписуванням архітектури цей пакет не є.
