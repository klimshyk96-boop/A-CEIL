# A·CEIL — приватність історичних звітів (12.11.2026)

## Виявлене
Сховище Supabase `roomator-reports` має `public=true`, тому прямий URL
`/storage/v1/object/public/roomator-reports/...` обходить перевірку доступу
в браузерному інтерфейсі та відкликання токена. Перед перемиканням:
- 96 об'єктів у bucket: 78 JSON, 18 HTML.
- 39 JSON із шаблоном `r/<20-hex>.json` (старі посилання в A·CEIL).
- 57 файлових об'єктів `report_....json/html` у корені bucket.
- Інший механізм immutable snapshot уже зберігається у приватній таблиці БД і
  доступний за коротким токеном через `aceil_get_public_report_snapshot`.

## Фаза 1 — реалізовано в цій гілці
- Edge Function `aceil-legacy-report` для лише 20-hex токенів:
  сервер отримує JSON через `/object/authenticated` зі службовим ключем
  тільки в Edge-середовищі, перевіряє `revoked` і `expiresAt`,
  повертає `no-store`, не пише токени в логи.
- `js/reports/092-aceil-public-report-page.js` більше не використовує
  публічний storage URL для старих токенів.
- Тести для приватного маршруту та повернення статусу відкликання.
- Функцію розгорнуто в Supabase незалежно від зміни видимості bucket.

## Фаза 2 — приватне сховище (після перевірки)
Після інтеграційного тесту **реального чинного 20-hex посилання** через gateway,
публікації нового JS на `a-ceil.pp.ua` та перевірки відкликаного/простроченого
токена застосувати `supabase/migrations/20261112080000_private_legacy_report_bucket.sql`.
Всі 96 об'єктів залишаються на місці; змінюється лише `public` bucket.
Перевірити що `/storage/v1/object/public/...` повертає відмову, а
`/r/<20-hex>` ще відкриває діючий звіт через Edge.

**Увага про сумісність:** прямі сторонні посилання на
`.../storage/v1/object/public/roomator-reports/report_*.json/html`
(57 об'єктів) після переведення bucket у private перестануть працювати.
Вони не мають високої ентропії/керованого токена, тому не можна безпечно
зберегти їх як анонімні прямі URL. До переключення потрібен інвентаризаційний
аудит розповсюджених посилань або рішення про їх закриття. Так само старий
закешований PWA має оновити JS.

Аварійний rollback bucket visibility у `supabase/rollback/20261112080000_private_legacy_report_bucket.down.sql`;
це відновлює доступ, але знову відкриває дані. Використовувати лише якщо
відновлення через приватний gateway технічно неможливе, і лише як тимчасовий захід.

## Не плутати
`status=ACTIVE` Edge Function підтверджує розгортання, **не** підтверджує
успішний запит реального звіту. Перед Фазою 2 необхідний позитивний
end-to-end тест валідного токена та негативні тести (відкликаний,
прострочений, неіснуючий). Не розголошувати їх у CI-логах.
