# Ручний чекліст перед релізом (те, що автотести не покривають)

Автотести працюють із підміненим Supabase, тому ці сценарії треба пройти руками на Preview-деплої Vercel
(реальна база, реальний телефон). Відмічайте результат прямо тут або в нотатках релізу.

## 0. Підготовка
- [ ] Відкрити Preview-URL у Chrome (десктоп) і в Safari на iPhone; для PWA — «Додати на початковий екран».
- [ ] DevTools → Console: **немає** порушень `Content Security Policy`; причину інших повідомлень `Refused to …` перевірено окремо.
- [ ] Application → Service Workers: нова версія активна, кеш `aceil-shell-<VERSION>` один.

## 1. Вхід і сесія
- [ ] Вхід e-mail+пароль; вихід; повторний вхід.
- [ ] Google OAuth: вхід, повернення в застосунок, сесія збережена після перезавантаження.
- [ ] Скидання пароля: лист приходить, посилання відкриває форму, новий пароль працює.
- [ ] Користувач без активного доступу / із простроченим доступом бачить обмеження, а не помилку.
- [ ] Офлайн: режим літака → застосунок стартує, відкриваються збережені проєкти.

## 2. Проєкти й синхронізація
- [ ] Створити об'єкт і 2 кімнати, перезавантажити, відкрити з іншого пристрою — дані збіглися.
- [ ] Змінити кімнату офлайн, повернути мережу — зміни синхронізувалися (черга pending sync порожня).
- [ ] Видалити кімнату/проєкт — не повертаються після перезавантаження і на іншому пристрої.
- [ ] Імпорт JSON-проєкту, експорт назад.

## 3. Звіти
- [ ] Менеджерський звіт: відкрити, «Друк/PDF», «Хмарне посилання», «Поділитися».
- [ ] Відкрити **публічне посилання `/r/<token>`** у приватному вікні (без входу): звіт показується, друк працює, масштаб працює.
- [ ] Старе посилання `/report/<token>` теж працює.
- [ ] Лічильник переглядів збільшується для стороннього сеансу і не збільшується для власника.
- [ ] PDF (jsPDF із `/vendor/`) генерується, у Network немає запитів до cdn.jsdelivr.net.
- [ ] iPhone Safari і встановлена PWA: той самий вбудований перегляд звіту.

## 4. Безпека (сценарії зловмисника)
- [ ] Створити проєкт/кімнату з назвою `"><img src=x onerror=alert(1)>` — ніде не з'являється alert (список, вкладки кімнат, звіт, попередній перегляд замірів).
- [ ] Із акаунта A виконати пряме читання приватного проєкту акаунта B через Supabase — дані недоступні. Окремо перевірити, що навмисно оприлюднений звіт доступний через призначений для цього RPC за токеном.
- [ ] Звичайний користувач не може викликати `admin_*` RPC (очікується помилка доступу).

## 5. Клієнтський калькулятор
- [ ] Власник публікує прайс; відкрити `/calculator/?c=<token>` у приватному вікні — ціни актуальні.
- [ ] Недоступний прайс (відкликаний токен) показує «недоступно», а не демо-ціни.

## 6. Пристрої
- [ ] iPhone Safari (мала ширина 390 px) і iPad: малювання контуру пальцем, масштаб, збереження.
- [ ] Android Chrome PWA: оновлення версії підхоплюється без ручного очищення кешу.
